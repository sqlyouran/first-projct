# Project Overview Spec

## Project Name
first-projct

## Description
A full-stack application project structured with OpenSpec (spec-driven development), Superpowers (composable AI skills), and Harness (engineering orchestration) methodology.

## Architecture
- **Spec Layer (OpenSpec)**: All features start as proposals, go through design, get specified, then implemented
- **Skills Layer (Superpowers)**: Composable development skills (TDD, code-review, debugging, etc.)
- **Orchestration Layer (Harness)**: Agent instructions, workflow enforcement, quality gates

## Principles
1. Agree before you build - Every feature requires an approved spec
2. Test-driven by default - Write tests before implementation
3. Incremental delivery - Small, reviewable changes
4. Traceability - Every code change links back to a spec
